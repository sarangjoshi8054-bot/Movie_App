# Movie App

A responsive movie discovery web application built using React and component-based architecture. The app uses the TMDB API to fetch and display movies, allowing users to explore trending and popular content in a clean and interactive interface.

Users can search for movies, add them to their favourites list, and remove them anytime with a smooth user experience. The project focuses on reusable React components, API integration, state management, and responsive UI design.

## Features

* Search and explore movies using TMDB API
* Add movies to favourites
* Remove movies from favourites
* Responsive design for different screen sizes
* Component-based architecture using React
* Dynamic movie data fetched from API

## Tech Stack

* React
* JavaScript
* CSS
* TMDB API

## Purpose of the Project

This project was built to strengthen understanding of React fundamentals, reusable component architecture, API handling, state management, and responsive frontend development while creating a practical real-world application.

## Note
